# amtx

micro:bit V2 専用のAM送信実験用拡張です。

- 0ピンにPWMで搬送波(16MHz ÷ 整数 kHz)を出します
- 音声は2ピンまたは内蔵マイクからADCで読み、デューティ比で振幅を変えます
- `AM送信開始` ブロックは戻りません。最後に置いてください
- analogReadPin / 音量ブロック / 音楽ブロックとは併用しないでください

```blocks
amtx.start(666, AmSource.Mic, 2, 60)
```

## 使用上の注意

電波法の微弱無線局の範囲(ごく近距離)で実験してください。
放送中の周波数は避け、空いている周波数を選んでください。

## メタデータ

```package
amtx=github:<あなたのユーザー名>/pxt-amtx
```
